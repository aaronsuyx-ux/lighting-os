# 供应链体系

## 供应链原则

1. 高感知价值不等于高复杂度。
2. 每个核心物料至少双供应来源。
3. 以小单快反控制库存风险，以标准化模块控制成本。
4. 质量前置到设计、打样、试产与包装阶段。
5. 全球市场必须先满足认证、插头、电压、标签与说明书要求。

## 供应链结构

```text
材料供应商 → 零部件供应商 → 总装工厂 → 第三方检测 → 3PL/区域仓 → 渠道/客户
```

## 供应商分级

| 等级 | 定义 | 合作方式 | 审核频率 |
| --- | --- | --- | --- |
| S 级战略工厂 | 核心系列、高稳定质量、愿意共同开发 | 年度框架协议、产能锁定、成本共创 | 每季度 |
| A 级核心工厂 | 量产能力稳定、价格合理 | 季度订单、质量评分 | 每半年 |
| B 级备份工厂 | 可承接常规 SKU 或紧急订单 | 小批量订单、备份产能 | 每年 |
| C 级测试工厂 | 新工艺、新材料、新区域 | 样品与试单 | 按项目 |

## 成本模型

```text
目标零售价 = 产品成本 / 目标成本率
产品成本 = 材料 + 加工 + 光源电器 + 包装 + 损耗 + 检测 + 内陆物流
落地成本 = 产品成本 + 国际物流 + 关税 + 仓储 + 履约 + 渠道费用
贡献利润 = 售价 - 落地成本 - 广告费用 - 售后成本
```

## 目标成本率

| 渠道 | 产品成本率目标 | 综合毛利目标 |
| --- | ---: | ---: |
| DTC | 18%-25% | 65%-72% |
| Amazon/平台 | 16%-22% | 55%-65% |
| 设计师批发 | 25%-35% | 45%-55% |
| B2B 项目 | 30%-45% | 35%-50% |

## 质量控制节点

| 节点 | 检查内容 | 放行标准 |
| --- | --- | --- |
| 设计评审 | 结构、电气、散热、安装风险 | 风险关闭后打样 |
| 样品评审 | 外观、尺寸、光效、稳定性 | 样品签封 |
| 试产 | 工艺稳定性、装配效率、良率 | 良率 ≥ 95% |
| 产中检 | 关键尺寸、表面、通电、配件 | AQL 达标 |
| 出货检 | 包装、跌落、标签、说明书 | 缺陷关闭 |
| 到仓检 | 破损、条码、数量、随机通电 | 异常入库隔离 |

## 合规清单

- 北美：UL/ETL、FCC、Prop 65、插头与电压标准。
- 欧盟：CE、RoHS、REACH、ERP、WEEE、能效标签。
- 英国：UKCA、BS 插头与标签要求。
- 澳洲：RCM、SAA、电气安全要求。
- 中东：GCC、SASO 或目标国家本地要求。

## 库存策略

| SKU 类型 | 补货策略 | 安全库存 | 评估周期 |
| --- | --- | --- | --- |
| Hero SKU | 预测补货 + 产能预留 | 60-90 天 | 每周 |
| Core SKU | 销售滚动预测 | 45-60 天 | 每周 |
| Trend SKU | 小单测试，不盲目补货 | 15-30 天 | 每 2 周 |
| Project SKU | 按订单生产 | 项目节点库存 | 按项目 |

## Costco 式效率借鉴

- 限制核心 SKU 数量，提升单品采购规模。
- 用会员/设计师计划换取稳定需求与低获客成本。
- 用透明价值主张强化“高品质、合理价”。
- 用长期供应商关系换取质量、成本与交付稳定。
