# 品牌体系

## 品牌定位

Lighting OS 品牌应成为“现代家居光环境的情绪设计师”：用天然材质、柔和光影与克制设计，让用户用一盏灯改变一个空间的情绪。

## 品牌金字塔

| 层级 | 内容 |
| --- | --- |
| Purpose | 让每个空间拥有更好的光与情绪 |
| Promise | Beautiful light, made simple |
| Positioning | 面向全球现代家庭与设计师的高感知价值灯饰品牌 |
| Personality | 温暖、克制、精致、可信、现代 |
| Proof | 天然材质、严选工艺、易安装、稳定交付、真实空间案例 |

## 品牌资产

- 品牌色：暖白、石灰、黑砂、香槟金、云石灰。
- 视觉语言：柔光、阴影、天然纹理、留白、空间尺度。
- 文案语言：少形容词，多场景；少参数堆砌，多体验解释。
- 核心内容：Before/After、材质故事、安装教学、设计师空间、用户家。

## Apple 式产品体验原则

1. 首页只突出少数旗舰系列，避免选择疲劳。
2. 产品命名保持系列化、易记忆、跨市场可发音。
3. 包装、说明书、安装流程与售后口径保持一致。
4. 产品页先讲空间效果，再讲材质与参数。
5. 每次上市都有清晰的“为什么存在”。

## 品牌不做清单

- 不做过度低价、牺牲质量的短期爆款。
- 不做与品牌光影语言冲突的夸张造型。
- 不做无法稳定交付或无法合规的产品。
- 不做只追逐流量但损害长期审美资产的内容。
