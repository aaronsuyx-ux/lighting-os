# 数据体系

## 数据原则

1. 让产品、供应链、品牌、渠道围绕同一套指标决策。
2. 数据不只用于复盘，也用于新品立项、补货、淘汰和预算分配。
3. 每个指标必须有负责人、刷新频率、行动阈值。
4. 先建立轻量 BI，再逐步形成自动化数据中台。

## 数据架构

```text
数据源
├── Shopify / DTC
├── Amazon / Marketplaces
├── TikTok / Meta / Google / Pinterest
├── ERP / OMS / WMS
├── 客服系统
├── 质量检验系统
└── 财务系统
    ↓
数据仓库
    ↓
指标层
    ↓
经营看板 / 告警 / 周报 / 预测模型
```

## 核心仪表盘

| 看板 | 使用者 | 核心指标 | 频率 |
| --- | --- | --- | --- |
| CEO Dashboard | CEO/管理层 | 销售、毛利、现金、库存、NPS | 每日 |
| Product Dashboard | 产品团队 | 新品成功率、转化、退货、评论 | 每周 |
| Supply Dashboard | 供应链 | 交付、良率、破损、成本、库存 | 每周 |
| Brand Dashboard | 品牌团队 | 自然流量、搜索量、UGC、社群 | 每周 |
| Channel Dashboard | 渠道团队 | ROAS、CAC、AOV、CVR、贡献利润 | 每日 |
| Project Dashboard | B2B 团队 | 线索、报价、赢单率、交期 | 每周 |

## 指标字典

| 指标 | 定义 | 行动阈值 |
| --- | --- | --- |
| New SKU Success Rate | 90 天达成销售、毛利、评分目标的新品占比 | 低于 30% 时复盘立项机制 |
| Contribution Margin | 售价扣除落地成本、广告、渠道、售后后的利润 | 连续 30 天为负则调整投放或价格 |
| Inventory Days | 当前库存 / 近 30 天日均销量 | 高于 90 天进入促销或清仓 |
| Damage Rate | 破损件数 / 出货件数 | 高于 1.5% 触发包装整改 |
| Review Rating | 渠道平均评分 | 低于 4.3 触发质量与客服复盘 |
| Design Lead Conversion | 设计师线索转客户比例 | 低于 15% 优化样品与报价流程 |

## 快反决策规则

- 内容点击率高、转化低：优化价格、产品页、信任元素。
- 加购高、支付低：检查运费、交期、安装顾虑与支付体验。
- 销售高、评分低：暂停放量，优先修复质量与说明书。
- 毛利低、销量高：启动成本工程、包装优化或价格测试。
- 搜索高、库存低：提高补货优先级，锁定产能。

## Year 1 到 Year 5 数据能力路线

| 年度 | 数据能力 |
| --- | --- |
| Year 1 | 手工报表 + 基础 BI + SKU 级 P&L |
| Year 2 | 自动化渠道看板 + 新品测试模型 + 补货提醒 |
| Year 3 | 多区域数据仓库 + 需求预测 + 供应链告警 |
| Year 4 | 用户分群 + LTV 模型 + 会员个性化推荐 |
| Year 5 | 全球经营中台 + AI 辅助选品、定价、补货与内容测试 |
